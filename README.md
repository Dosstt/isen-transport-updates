# Isen Transport – Update-Kanal

Hier liegt nur die **signierte** Versionsinfo für installierte Isen-Transport-PCs:

- `release.json` – Version, Datum, Hinweise, Adresse und SHA-256 der Compose-Datei, Ed25519-Signatur
- `<version>/docker-compose.yml` – Images per Digest festgelegt, keine Passwörter

Kein Programmcode, keine Kundendaten. Installierte PCs übernehmen nur Updates mit gültiger Signatur.
